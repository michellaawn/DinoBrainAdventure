# Dino Brain Adventure
**Deskripsi Singkat**

Dino brain adventure merupakan game edukatif bertema petualangan dinosaurus yang menggabungkan unsur permainan dengan Cognitive Science. Game ini ditargetkan untuk anak SD kelas 1 hingga kelas 3. Pemain mengendalikan dinosaurus untuk melewati berbagai rintangan dan menyelesaikan tantangan yang melatih _pattern recognition, attention, dan, memory._ Setiap tantangan yang berhasil diselesaikan, pemain akan memperoleh skor dan melanjutkan petualangan ke level berikutnya dengan tingkat kesulitan yang meningkat.

**Project Structure**

Struktur Game

Dino Brain Adventure terdiri dari beberapa bagian utama, yaitu:

1. Main Menu
   - Start Game
   - How to Play
   - Exit

2. Gameplay
   - Pemain mengontrol Dino untuk bergerak dan melompat.
   - Mengumpulkan telur untuk mendapatkan poin.
   - Menghindari musuh dan rintangan.
   - Memiliki sistem health dan score.

3. Cognitive Challenge
   - Pattern Recognition
   - Attention
   - Memory

5. Level
   - Level 1: Pola Recognition 
   - Level 2: Attention
   - Level 3: Memory
   

6. Result
   - Menampilkan skor akhir.
   - Menampilkan hasil tantangan kognitif.
   - Menampilkan status berhasil atau game over.
